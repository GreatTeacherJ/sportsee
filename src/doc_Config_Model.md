| Paramètre                             | Type                                             | Explication                                                                                                                                       |
| ------------------------------------- | ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| `model`                               | string                                           | Identifiant du modèle à utiliser (ex: "gpt-4o", "gpt-5.4-mini"). Détermine coût, vitesse, capacités.                                              |
| `input`                               | string \| array                                  | Le contenu envoyé au modèle. String simple ou tableau de messages structurés avec rôles.                                                          |
| `input[].role`                        | "system" \| "user" \| "assistant" \| "developer" | Définit qui "parle". `system`/`developer` = instructions de comportement, `user` = requête humaine, `assistant` = réponses précédentes du modèle. |
| `input[].content`                     | string \| array                                  | Le texte (ou contenu multimodal : image, fichier) associé à ce message.                                                                           |
| `store`                               | boolean                                          | Si `true`, la réponse est sauvegardée côté OpenAI et récupérable via son ID plus tard (pour du multi-tour).                                       |
| `temperature`                         | number (0-2)                                     | Contrôle l'aléatoire des réponses. Bas = déterministe/répétitif, haut = créatif/imprévisible.                                                     |
| `top_p`                               | number (0-1)                                     | Alternative à `temperature` pour contrôler la diversité (nucleus sampling). Rarement combiné avec `temperature`.                                  |
| `max_output_tokens`                   | number                                           | Limite la longueur de la réponse générée, en tokens.                                                                                              |
| `stream`                              | boolean                                          | Si `true`, la réponse arrive en flux (chunks) au lieu d'un bloc complet — utile pour affichage progressif.                                        |
| `tools`                               | array                                            | Liste de fonctions/outils que le modèle peut appeler (function calling, web search, code interpreter).                                            |
| `tool_choice`                         | string \| object                                 | Force ou laisse le modèle choisir d'utiliser un tool spécifique, "auto", ou aucun.                                                                |
| `previous_response_id`                | string                                           | Permet de chaîner une nouvelle requête à une réponse précédente stockée (`store: true`), pour garder le contexte sans renvoyer tout l'historique. |
| `instructions`                        | string                                           | Raccourci pour définir un system prompt sans passer par `input` en tableau.                                                                       |
| `metadata`                            | object                                           | Paires clé-valeur arbitraires pour attacher des infos custom à la requête (traçabilité, logs).                                                    |
| `reasoning` (modèles o1/o3/reasoning) | object                                           | Configure l'effort de raisonnement interne du modèle (`effort: "low"/"medium"/"high"`).                                                           |
